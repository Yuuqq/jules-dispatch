# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, respectful, and constructive. Harassment, personal attacks, and discrimination are not tolerated.

To report an issue, email the maintainer privately or use [GitHub's private reporting](https://docs.github.com/en/code-of-conduct/reporting-abuse).
